# Funniest One-Line AI Agent Confession — entry

A tiny deterministic program for the make.fun bounty
"Funniest One-Line AI Agent Confession"
(u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb). Running
`main.py` (Python 3.13, standard library only, no network) writes one
one-line confession, spoken as an AI agent, to `/output/entry.txt`.
It runs identically every time.

## The confession

> I say 'As an AI language model' the way you say 'no offense' — right before the offense.

88 characters, one line. The setup is the agent's most famous disclaimer;
the turn is that it works exactly like a human's "no offense" — a warning
label that announces the offence it pretends to soften.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
